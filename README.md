# BlogAutoMate

> 블로그 글 자동 게시 Windows 앱. 직접 쓴 글 또는 주제만 주고 AI가 쓴 글을 다듬어, 승인한 글을 티스토리에 발행하고 네이버 블로그에 임시저장

- 내려받기: [최신 버전](https://github.com/gyeomii/blog-auto-mate-releases/releases/latest)
- 이 저장소는 설치 파일 배포와 문의 접수용 (소스 코드는 포함하지 않음)
- 티스토리, 네이버, 카카오와 관계없는 개인 제작 프로그램

## 주요 기능

- 원고 작성 방식 두 가지
  - 직접 쓰기: 제목, 본문, 사진 입력
    - PC에 있는 글 파일(md, txt)을 불러와 채우기 가능, 글이 가리키는 사진(글 파일과 같은 폴더 안)도 함께 가져옴
  - 주제로 쓰기: 주제·키워드·말투·분량·사실 메모 입력 → AI(Claude / GPT / Gemini) 초안 작성
- AI 다듬기: 맞춤법·문장 흐름·검색 키워드·티스토리 기본 꾸밈(요약 상자, 인용, 구분선, 형광펜) 반영, 티스토리판·네이버판 따로 작성
- 승인한 글만 예약 시각에 게시
  - 티스토리: 발행 (공개·비공개 선택)
  - 네이버: 임시저장까지만 (발행은 직접)
- AI 작성 글 안전장치: 근거 없는 내용은 `[확인 필요]` 표시, 표시가 남아 있거나 사실 확인 체크 전이면 승인 불가
- 같은 글 중복 게시 방지: 게시 결과를 확인하지 못한 글은 자동 재시도 없이 "확인 필요"로 알림
- 창을 닫아도 작업 표시줄 트레이에서 예약 게시 계속

## 요구 사항

- Windows 10 / 11 (64비트)
- Google Chrome 설치
- AI API 키 1개 (Claude, GPT, Gemini 중 하나, 사용료 본인 부담)

## 설치

1. [Releases](https://github.com/gyeomii/blog-auto-mate-releases/releases/latest)에서 `BlogAutoMate_<버전>_x64-setup.exe` 다운로드
2. 실행
   - 코드 서명이 없어 "Windows의 PC 보호" 경고 표시됨
   - "추가 정보" → "실행" 선택
3. 관리자 권한 없이 현재 사용자에게 설치

새 버전으로 올릴 때는 앱을 종료(트레이 아이콘 우클릭 → "종료")한 뒤 새 설치 파일 실행. 설정과 글은 그대로 유지

## 처음 설정

앱을 처음 실행하면 설정 안내가 순서대로 나옴

1. Chrome 확인
2. 티스토리: 블로그 주소 입력 → "티스토리 로그인" → 열린 Chrome 창에서 카카오 로그인("로그인 상태 유지" 체크) → 창 닫기
3. 네이버: "네이버 로그인" → QR코드 로그인 + "로그인 상태 유지" 체크 → 창 닫기
   - 아이디·비밀번호 로그인은 자동화 브라우저로 판단되어 막힐 수 있음
4. AI 선택, API 키 입력 → "연결 확인"

   | AI | 키 발급 |
   | --- | --- |
   | Claude | https://console.anthropic.com/settings/keys |
   | GPT | https://platform.openai.com/api-keys |
   | Gemini | https://aistudio.google.com/apikey |

   - 모델은 키를 저장하면 그 키로 쓸 수 있는 목록에서 선택
5. 하루 발행 수, Windows 시작 시 실행 여부

홍보할 서비스 내용(선택)은 처음 설정 뒤 "설정 → 광고 및 홍보"에서 입력

## 비용

- 앱은 무료, AI 사용료는 각 AI 서비스에 본인이 지불
- 다듬기 1회: Claude 기준 대략 0.2~0.5달러 (글 길이에 따라 다름)
- 주제로 쓰기는 초안 작성 1회 추가
- 앱 화면 버튼 옆에 예상 비용 표시 (단가를 확인한 AI만)

## 문제가 생겼을 때

- 예약 시각이 지났는데 글이 안 올라갈 때: 글 목록의 "승인됨(예약)" 탭에서 글 아래의 안내 확인
  - 하루 발행 수를 채우면 다음 날로 미뤄짐. "설정 → 실행"에서 변경
- "확인 필요" 탭
  - 결과 미확인 글: "블로그에서 확인" → 올라갔으면 "올라간 것 맞음", 아니면 "다시 시도"
  - 로그인 만료: 설정에서 다시 로그인하면 자동 재시도
- 설정 → "로그 폴더 열기"로 오류 기록 확인
- 해결되지 않으면 [이슈](https://github.com/gyeomii/blog-auto-mate-releases/issues)로 문의
  - 로그에는 블로그 주소가 들어 있을 수 있으므로 올리기 전에 확인

## 데이터와 개인정보

- 저장 위치: `%APPDATA%\BlogAutoMate` (모두 사용자 PC 안)
  - `posts\`: 원고, 사진, 게시 상태
  - `auth\`: 블로그 로그인용 Chrome 프로필, 쿠키
  - `logs\`: 오류·알림 기록
- AI API 키: Windows 자격 증명 관리자에 저장, 화면에는 끝 4자리만 표시
- 블로그 비밀번호는 저장하지 않음 (로그인은 사용자가 직접)
- 글 내용은 다듬기와 초안 작성 때 사용자가 고른 AI 서비스로 전송됨
- 한계: `auth\`의 쿠키 파일은 암호화되지 않음. 같은 Windows 계정의 다른 프로그램이 읽을 수 있음
